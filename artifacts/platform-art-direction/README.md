## Data provenance

Company relationships and imagery come from the existing reviewed catalog. Quaker has no
reviewed image and deliberately shows its existing placeholder. The issuer feed is intercepted
as unavailable in visual QA; no current price or investment availability is invented.

Portfolio and Account use the existing isolated localhost synthetic fixtures: 25 USDC cash,
1.25 PEPx units, 150 USDC acquisition cost, and an `.invalid` account. These are test data, not
real money, personal holdings or live execution. Assistant starts with no generated response.
No paid recognition, wallet signing, funding or transaction is performed.

See [the composition review](../../docs/PLATFORM_ART_DIRECTION.md) for scope and verification.
These screens are proposed for user approval, not authorization to propagate the layouts.
