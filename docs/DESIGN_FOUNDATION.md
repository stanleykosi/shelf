# Shelf visual foundation

Status: accepted for the global shell, Home, and Discover on 2026-09-23.

Direction: **Premium Institutional Editorial Research**. Shelf combines a quiet software shell, editorial research hierarchy, and progressive explanation. Simply Wall St remains the product-research philosophy; Linear informs shell precision and density; Quartr informs evidence and company-research presentation. Their branding is not copied.

## Foundation

| Area | Foundation |
|---|---|
| Type | UI sans stack. Display 38–68px; page title 38px; section title 22–26px; body 15–17px; metadata 12–14px. Meaningful mobile copy never uses 10–11px text. |
| Spacing | 4, 8, 12, 16, 24, 32, 48, 64, 80px. Section rhythm favors 52–74px rather than oversized landing-page gaps. |
| Layout | 1328px maximum desktop canvas, 12 columns, 24px gutters. Mobile uses one column and 16px page edges. |
| Neutral palette | Canvas `#f7f7f5`; surface `#fff`; graphite `#171918`; secondary `#626865`; rules `#dddfdc` and `#bfc4c0`. |
| Shelf accent | Forest `#174d3b`; strong `#103a2c`; pale `#e8f0ec`. Accent is reserved for primary action, selection, verification, and identity. |
| Geometry | 0px for structural sections/tables; 4–6px for controls and genuine cards; circular treatment only for fallback identity. |
| Elevation | No routine shadows. One low search elevation; overlays use a neutral scrim. |
| Controls | 42–56px depending on hierarchy; all interactive targets remain at least 44px on touch. |
| Icons | Lucide line icons, normally 16–20px. Icons clarify action/state and are not decorative prefixes for every label. |
| Motion | 120–180ms; opacity, color, and small composite-only movement. The filter sheet uses a 180ms ease-out entry; reduced motion keeps only the fade. |

## Composition rules

- Build pages with grid, typography, whitespace, and rules before adding containers.
- Reserve cards for discrete objects such as Products and the single Relationship Explorer.
- Product, Brand, and Company use distinct presentations: visual tile, structured row, research table.
- Evidence appears once at the level where it helps a decision; avoid repeated verification badges.
- Search and filter state remain URL-backed. Desktop filters live in a left rail; mobile filters use a bottom sheet and active removable filters.
- Research precedes exposure. Market and instrument state never dominate recognition or imply a recommendation.
